## Опис предмету

На курсі ми вивчаємо об'єктно-орієнтоване програмування на Python:
- класи та об'єкти;
* інкапсуляцію, наслідування і поліморфізм;
+ магічні методи та роботу з винятками;
- структурування проєктів і читабельний стиль коду.

Мета курсу: навчитися розробляти зрозумілі, масштабовані та акуратні програми, де кожен клас знає свою відповідальність.
